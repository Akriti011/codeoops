What the workspace gives you

One surface for every repository you track, with the documentation engine kept at arm's length behind a single boundary.

    The boundary

    CodeOops orchestrates. CodeWiki documents.

    There is no second documentation engine here, no language model in the request path and no fallback document. If the engine has not produced an artifact, the workspace says exactly that.
